# Aztraliz Point — actualizaciones Windows

Repositorio oficial de distribución de instaladores de **Aztraliz Point**. Contiene binarios, firmas y checksums; el código fuente se mantiene en un repositorio privado.

Descarga un instalador desde [Releases](https://github.com/GabrielHDL/aztraliz-point-updates/releases). A partir de Point 0.2.6, también puedes consultar nuevas versiones desde **Ajustes → Este equipo → Actualizaciones de Point**. Las versiones anteriores necesitan instalar el primer paquete manualmente.

Point comprueba actualizaciones una vez por apertura, valida la firma del paquete y solicita una acción explícita para instalar. Las publicaciones del repositorio se habilitan para cada canal desde el servicio de Aztraliz.

Los archivos `.sig` corresponden al actualizador. No equivalen a un certificado Authenticode de Windows. El archivo `SHA256SUMS.txt` permite cotejar la integridad de la descarga.
